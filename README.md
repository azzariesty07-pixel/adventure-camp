- Adventure Camp
- Adventure Camp merupakan program berbasis console yang dibuat menggunakan bahasa pemrograman C untuk membantu proses penyewaan peralatan camping. Program ini dirancang untuk mempermudah pengguna dalam melihat daftar peralatan, melakukan penyewaan, menghitung biaya sewa secara otomatis, serta melihat riwayat transaksi.
